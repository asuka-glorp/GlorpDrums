Core Features & Capabilities

A breakdown of the sound engine, mixer console, practice deck, and authoring tools.

ARCHIVE ENGINE

Native GlorpKit Format (.glorpkit)

Eliminates sprawling directories of thousands of loose audio files by packaging complete drum kits into a standardized ZIP64 archive. Samples are streamed directly from disk via zero-copy memory mapping (mmap) without extracting to temporary files.

  • Zero extraction overhead: instantaneous kit loading
  • ZIP64 support for massive multi-gigabyte libraries
  • Backward compatibility with legacy DrumGizmo XML setups
EXPRESSION & CALIBRATION

Multi-Zone & E-Drum Calibration

Tailored for electronic drum kit responsiveness with smooth continuous hi-hat pedal tracking across CC#4 (equal-power crossfading between Closed, Semi-Open, Open, and Splash), 15ms anti-click cymbal choke damping, and customizable velocity response curves.

  • Snare Head, Rimshot, RimClick, and Muffled articulations
  • Dynamic foot chick & rapid stomp-and-release splash gestures
  • Linear, Logarithmic, Exponential, and S-Curve response presets
MIXING CONSOLE

16-Bus Multi-Out & Bleed Matrix

Route individual kit pieces or microphone groups across 16 discrete stereo DAW stem pairs (Out 1/2 through Out 31/32) for multitrack mixing in Reaper, Ardour, or Bitwig.

  • Acoustic Bleed Matrix: Simulates natural room crosstalk between instruments with delay compensation.
  • Per-Channel DSP FX: Inline 3-band parametric EQ, VCA drum compressor, tape/tube saturation, and dual-envelope transient shaper.
  • Stereo Fold-Down: Automatically protects aux-routed voices on standard 2-channel stereo tracks.

Per-mic channel strips & master limiter

Acoustic crosstalk matrix with spill controls

Full-width waveform deck with tempo detection & 3-column setlist console

PRACTICE & REHEARSAL

Setlists & Tempo Detection

The integrated practice suite allows drummers to rehearse against backing tracks, detect tempos automatically, organize multi-song setlists, and record performances.

  • Smart Tempo Detection: Multi-window spectral flux novelty analysis detects track BPM, downbeat phase, and confidence score.
  • Persistent Song Library: Saves track tempo, Beat-1 grid offset, and meter to song_library.xml for instant recall in any setlist.
  • Sequential Standby Preloading: Zero-latency transitions between setlist songs with phase-locked count-ins.
  • Dual WAV + MIDI Capture: Records uncompressed 24-bit audio and SMF Type 1 MIDI files simultaneously.

GlorpKit Studio

The companion standalone visual application for designing, editing, and packaging drum kits.

STANDALONE APP

GlorpKit Studio is a dedicated authoring tool bundled directly with GlorpDrums. It lets you create custom multi-articulation drum kits from raw audio samples or layered artwork:

OpenRaster (.ora) Artwork Import Extract layered graphics directly from Krita or GIMP, auto-assign sprites to instruments, and preserve physical stage coordinates.
Custom Velocity & Round-Robin Matrix Add up to 13 velocity layers and custom round-robin columns, with automated RMS/Peak hit power sorting.
High-Level Microphone Routing & Glow Picker Batch-route whole instruments or zones to specific mic channels in one click, with channel deletion and an interactive 360° Hue color wheel.

Building from Source

Compile GlorpDrums on Linux (x86_64) using CMake and GCC or Clang.

bash terminal

# 1. Clone repository with submodules (JUCE)

git clone --recurse-submodules https://github.com/asuka-glorp/GlorpDrums/.git

git clone --recurse-submodules https://github.com/asuka-glorp/GlorpDrums.git

cd GlorpDrums

# 2. Configure release build with CMake

cmake -B build -DCMAKE_BUILD_TYPE=Release

# 3. Compile all targets (GlorpDrums, VST3, LV2, GlorpKitEditor)

cmake --build build -j$(nproc)

# 4. Verify test suite

./build/verify_fixes && ./build/glorp_core_tests

Prerequisites

  • • Compiler: C++20 compliant (GCC ≥ 11 or Clang ≥ 14)
  • • Build System: CMake ≥ 3.22
  • • Audio Drivers: ALSA development headers (libasound2-dev)
  • • Graphics / GUI: FreeType & X11 development libraries (libx11-dev, libxrandr-dev, etc.)
